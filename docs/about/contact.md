# Contact

Questions, bug reports and feature requests go to the GitHub issue tracker:
<https://github.com/Barbhuiya12/TorchVIC/issues>.

## Reporting a problem

Please search the [Known limitations](limitations.md),
[Troubleshooting](../troubleshooting.md) and the open issues first. For a bug
report include:

* the TorchVIC version (`torchvic --version`) and the torch version;
* the global parameter file and the command line;
* the complete message of the run, which prints every decision TorchVIC takes
  from the inputs;
* the device (CPU, or the GPU model) and the precision;
* a small case that reproduces the problem, if you can make one. It is the
  most useful addition.
