# VIC 5 image-driver options in TorchVIC

Generated from `torchvic/io/options.py` (`python -m torchvic.io.options > docs/OPTIONS.md`, and `python -m torchvic.io.options README.md` for the README's summary); `tests/test_verification_matrix.py` fails when this file and the code disagree.

Every key VIC 5.1.0's image driver reads from the global parameter file, and every value of it: **implemented** (TorchVIC runs it as VIC does, under the condition stated), **no effect** (VIC accepts it and it cannot change a result in a configuration TorchVIC runs; announced in the log) or **refused** (the run stops, naming the option). A value not listed is refused. A key that is not an image-driver option is announced and ignored, as VIC warns and ignores it.

Defaults that matter: VIC's IMPLICIT and EXP_TRANS are TRUE until a `FROZEN_SOIL FALSE` line resets them, and VIC refuses them TRUE with QUICK_FLUX TRUE, so a file must carry `FROZEN_SOIL FALSE` (or set both FALSE), as VIC itself requires.
